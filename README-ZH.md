## 📖 概述

**Simple Wordbook** 是一款为 [Obsidian](https://obsidian.md/) 设计的单词/短语高亮与学习管理插件。  
它能自动高亮您笔记中出现在自定义词库里的单词，并提供侧边栏、查词面板、词库管理、学习中心、掌握状态追踪、AI 辅助查询、TTS 发音、导入导出等完整学习工具链。

## 🚀 安装方法

### 从 Obsidian 社区插件市场安装（推荐）

1. 打开 Obsidian 设置 → 第三方插件 → 社区插件。
2. 点击 **浏览**，在搜索框中输入 `Simple Wordbook`。
3. 找到插件后，点击 **安装**。
4. 安装完成后，在已安装插件列表中点击 **启用**。

### 手动安装

1. 下载 `main.js`、`manifest.json`、`styles.css`。
2. 将其放入你的 vault 的 `.obsidian/plugins/simple-wordbook/` 目录。
3. 在 Obsidian 设置中启用插件。

### 通过 BRAT 安装（测试版推荐）

1. 安装 [BRAT](https://obsidian.md/plugins?id=obsidian42-brat) 插件并启用。
2. 在 BRAT 设置中点击 **Add Beta Plugin**。
3. 输入仓库地址：`https://github.com/Bin-T/obsidian-simple-wordbook`。
4. 点击 **Add Plugin**，然后回到社区插件列表启用即可。

## 🎮 使用指南

### 1. 添加单词本

1. 在 vault 中新建一个空白 `.json` 文件，或导入单词格式如下的 `.json` 文件词库（词库格式为 JSON 数组，每个单词对象需包含 `word` 字段，可选 `aliases`、`definition`、`phonetic`、`color`、`lang` 等）：

```json
[
  {
    "word": "abandon",
    "aliases": ["abandoned", "abandoning"],
    "phonetic": "英 /əˈbændən/ 美 /əˈbændən/",
    "definition": "**释义**\n放弃，遗弃\n\n---\n\n**例句**\nHe abandoned his car in the snow.",
    "color": "red",
    "lang": "en"
  }
]
```

2. 打开 **设置 → Simple Wordbook → 文件**，点击 **「添加单词本」** 选择已有文件，或点击 **「新建单词本」** 创建新文件。
3. 文件会出现在列表中，可通过开关启用/禁用，或设为只读。

也可以从[词库仓库](https://github.com/Bin-T/obsidian-simple-wordbook/tree/main/wordbooks) 下载现成词库。

#### 词库文件的更多说明

- 支持拖拽排序，调整词库优先级。
- 支持 **只读模式**，设为只读后无法编辑或删除该词库的单词。
- 若文件被重命名或移动到其他位置，插件会自动更新词库路径。
- 释义支持完整的 Markdown 格式，可包含表格、列表、内部链接等。
- 使用 `---` 分隔多个标签页，标签名取每段开头的 `**标题**`。
- 未设置标题时，第一段默认名为「释义」，后续为「内容 2」「内容 3」等（详见 FAQ）。

### 2. 单词侧边栏使用

- 点击左侧 Ribbon 中的图标或命令打开单词侧边栏。
- 单词侧边栏会自动显示当前文档中匹配的单词卡片。
- 点击卡片上的 **😊/😐** 标记掌握/取消掌握。
- 点击 **👁/👁‍🗨** 标记忽略/取消忽略。
- 点击单词可发音（需配置 TTS）。
- 对未设置只读词源的单词卡片可右键 **编辑/删除** 单词，或 **导出为 Markdown**。

#### 单词侧边栏卡片

- 分为 **「学习 / 掌握 / 忽略」** 三个标签页，每个标签页显示对应数量。
- 卡片显示：单词、音标、释义、来源词库、颜色标签。
- 卡片内容区域独立滚动，支持多段落释义标签切换。
- 支持卡片搜索过滤，搜索时自动切换到首个匹配的标签页。
- 支持 **折叠释义** 与 **模糊释义**。
- 点击单词可发音；右键单词可复制单词、音标、释义、来源或全部信息。
- 右键卡片可编辑、删除、导出为 Markdown；只读词库不可编辑/删除。
- 可设置 **掌握/忽略模式**：全局统一 或 按词源独立管理。

### 3. 查词面板使用

- 点击左侧 Ribbon 中的图标或命令打开查词面板。
- 输入单词后，点击 **「本地查询」** 在词库中检索。
- 点击 **「AI 查询」** 调用 AI 获取详细释义。
- 在 **「提示词」** 下拉菜单中切换提示词。
- 查询结果可直接点击 **「保存单词」** 存入词库。
- 本地查询结果中的卡片，右键同样支持 **编辑**、**删除** 和 **导出为 Markdown**。

#### 回车模式

在 **设置 → 常规 → 查词面板 → 回车模式** 中可选：

- **仅本地**：回车只查本地词库。
- **仅 AI**：回车只查 AI。
- **本地优先**：先本地，未找到再调用 AI。

> 提示：在输入框中按 `Shift + Enter` 始终强制走 AI 查询。

#### 本地查询模式

在 **设置 → 常规 → 查词面板 → 本地查询模式** 中可选：

- **智能匹配（综合排序）**
- **精准匹配（仅完全一致）**
- **前缀匹配**
- **包含匹配**
- **模糊匹配（允许拼写错误）**

#### 最大结果数

在 **设置 → 常规 → 查词面板 → 最大结果数** 中修改设置，本地查询最多返回的结果数量（1-100）。

#### 查询历史

- 点击输入框右侧的 **历史** 按钮打开历史下拉浮层。
- 支持搜索、固定、清空历史。
- AI 查询结果会被缓存，点击历史项可直接恢复结果。

### 4. 词库管理使用

- 点击左侧 Ribbon 中的图标或命令打开词库管理。
- 顶部工具栏：搜索框、颜色筛选、状态筛选、来源筛选、排序字段、排序方向、全选。
- 表格列：选择、单词、音标、释义、来源、颜色、状态。
- 双击行可编辑单词；右键行可打开上下文菜单。
- 选中行后，批量操作栏显示：修改颜色、标记掌握、取消掌握、标记忽略、取消忽略、删除选中、清空选择。
- 顶部统计栏显示总数、学习中、掌握、忽略的数量与比例。

### 5. 学习中心使用

- 点击左侧 Ribbon 中的图标或命令打开学习中心。
- 顶部显示今日进度 `今日：X/Y`。

#### 复习标签

- 选择词库 → 查看统计 → 点击 **「开干！💪」** 开始复习。
- 卡片正面：单词、音标；双击或按空格翻面。
- 卡片背面：释义（支持多标签页，按数字键 1-9 切换）。
- 反馈按钮：
  - 2 按钮模式：**忘记（←）/ 记得（→）**
  - 4 按钮模式：**忘记（←）/ 困难（↓）/ 良好（→）/ 简单（↑）**
- 其他快捷键：
  - `B`：标记 / 取消标记（需开启「再复习标记」）
  - `Alt + P`：朗读单词
  - `Ctrl + ←/→`：上一个 / 下一个
  - `R`：集中复习标记词
  - `A`：再来一轮
  - `Q`：返回准备界面

##### 智能拼写

开启后，翻到卡片背面会出现拼写按钮：

- 点击 **「拼写 (S)」** 进入拼写模式，按格子逐字输入。
- **「显示答案 / 隐藏答案」**：显示半透明提示，按 `Alt + A` 可快速切换。
- **「退出拼写」**：按 `Alt + E` 可快速退出。
- **「再拼一次 (S)」**：完成一轮后原地重来。
- 拼错时格子会抖动；同一格错 3 次会自动填入正确答案并标红。
- 支持多种单词遮罩：模糊 / 隐藏 / 透明 / 占位符 / 无遮罩。
- 支持拼写前 / 拼写后自动朗读。
- 支持自定义拼错重置方式（单格重置 / 全部重置）与格子占位符。

#### 已掌握标签

- 查看全部已掌握单词。
- 支持搜索。
- 可取消掌握，恢复学习。

#### 等级标签

- 按等级（0~5）、难度系数、复习次数查看单词。
- 支持搜索、等级筛选、类型筛选（新手词 / 稳步词 / 高效词 / 吃力词 / 顽固词）、排序。
- 可标记掌握 / 取消掌握。

#### 统计标签

- 顶部概览卡片：总词汇、学习占比、掌握占比、忽略占比、今日进度、连续学习天数。
- 环形图：学习状态分布。
- 折线图：30 天学习趋势。
- 条形图：等级分布。
- 列表：来源分布、颜色分布。

#### 设置标签

- 每日目标、单次复习上限
- 自动翻转（秒）
- 新词补充顺序（顺序 / 随机）
- 复习排序（到期优先 / 高等级优先 / 低等级优先）
- 显示音标、释义以标签页显示
- 精细反馈（4 按钮模式）
- 再复习标记
- 智能拼写（含遮罩、拼写前后发音、遮罩占位符、拼错重置、格子占位符）
- 复习间隔（等级 0~4，默认 1/2/4/8/16 天）
- 高级算法参数（基础难易系数、额外难易系数、奖励阈值、难易系数范围、搁置参数、惩罚阈值）

### 6. 右键菜单

- **编辑模式中选中文本**，右键 → **添加单词/短语** 快速添加单词。
- **编辑模式中选中文本**，右键 → **查词：xxx** 打开查词面板并自动查询（始终走 AI）。
- **单词侧边栏 / 查词面板卡片**，右键 → **编辑** / **删除** / **导出为 Markdown**。
	- 「编辑」和「删除」仅对 **非只读** 词库中的卡片显示。
	- 「导出为 Markdown」**始终可用**。
- **单词右键复制菜单**，复制单词、音标、释义、来源路径、全部信息。

### 7. 悬停预览

- 将鼠标悬停在任何高亮单词上，会自动弹出释义弹窗。
- 弹窗显示音标、完整释义、多词源来源。
- 弹窗内可切换多词源、标记掌握、定位侧边栏。
- 支持 **模糊释义** 模式（默认模糊，悬停清晰）。

### 8. 例句提取与 AI 语境解释

在添加/编辑单词时，点击释义框右上角的引号图标，可打开例句提取器：

- **例句提取方式**：
	- 按空行分隔：提取光标所在的完整段落。
	- 按换行分隔：提取光标所在的行。
	- 按句子边界：智能识别 `。！？.!?`，提取光标所在的句子。
	- 按列表项：识别列表标记，提取光标所在的列表项。
- **AI 语境解释**：调用 AI 结合选中语境解释单词含义，可插入到释义中。
	- 支持自定义系统提示词与提示词内容，提示词会自动保存。

### 9. 导入导出

#### 导入

- 在 **设置 → 文件 → 导入** 中，点击 **「导入」** 选择 `.txt` 文件。
- 支持导入 **掌握词表** 或 **忽略词表**。
- 每行一个单词，或用 `,` `，` `;` `；` `Tab` 分隔。
- 已存在或冲突的单词会自动跳过（忽略优先于掌握）。

#### 导出单词本

在 **设置 → 文件 → 导出单词本** 中打开导出窗口：

- 选择要导出的词库（仅显示已启用的词库，可多选）。
- 选择导出范围：全部 / 学习中 / 掌握 / 忽略。
- 选择导出格式：
  - **Markdown `.md`**：适合阅读/打印。
  - **Anki 兼容 TXT (TSV)**：制表符分隔，可直接导入 Anki。
- 可选包含：音标、别名、释义、来源、状态、语言字段。
- TXT 格式额外支持：
  - **转换为 HTML**：将 Markdown 粗体和换行转为 `<b>` 与 `<br>`。
  - **每行一个单词**：无引号，换行转空格。
- 可选择保存文件夹与文件名。

#### 导出掌握/忽略

在 **设置 → 文件 → 导出掌握 / 导出忽略** 中，导出为每行一个单词的 `.txt`。

#### 导出单卡片

右键单词卡片 → **导出为 Markdown**，将单个单词卡片导出为独立的 `.md` 文件。

### 10. 高亮配置

在 **设置 → 常规 → 高亮与预览** 中可调整：

- 启用/禁用自动高亮
- 启用/禁用悬停预览
- 模糊释义
- 折叠释义
- 启用/禁用掌握/忽略按钮
- 高亮颜色：跟随卡片颜色或自定义
- Markdown 高亮透明度：默认 30%
- PDF 高亮透明度：默认 70%
- 下划线样式与颜色
- 粗体
- 文本颜色高亮模式（仅 Markdown）
- 高亮范围（路径过滤）

#### 高亮范围

- 开启后，可设置 **仅包含** 或 **仅排除** 指定路径。
- 每行一个路径：
  - Markdown 文件需包含 `.md` 后缀。
  - 文件夹路径会匹配其下所有文件。
  - 输入 `*` 可匹配仓库根目录下的所有文件（不含子文件夹）。

### 11. 发音配置

- 点击单词即可播放发音。
- **网络 TTS**：
  - 内置预设：有道（仅英语）、百度（多语言）、Google（多语言）。
  - 支持自定义 URL 模板，可用 `{{word}}`、`{{type}}`、`{{accent}}`、`{{lang}}`、`{{rate}}` 占位符。
  - 支持美式 / 英式发音切换（仅对使用 `{{type}}` 的模板生效）。
  - 支持按预设调整语速范围。
- **系统 TTS**：
  - 使用浏览器/操作系统内置语音引擎，完全离线。
  - 可指定系统语音、语速、音高。
  - 「默认」语音会根据单词的 `lang` 字段自动匹配；无匹配时自动回退到网络 TTS。
- **多语言管理**：
  - 可新增/编辑/删除语言。
  - 为每种语言配置在 Google / 百度 / 系统 / 自定义预设下使用的代码。
  - 可设置默认发音语言。

## ⚙️ 配置详解

### 文件

| 配置项 | 说明 |
|---|---|
| 单词本文件 | 已添加的单词本列表，可启用/禁用/删除/拖拽排序 |
| 只读模式 | 设为只读后无法编辑或删除该词库的单词 |
| 掌握/忽略模式 | 全局统一 或 按词源独立管理 |
| 掌握/忽略文件路径 | 自定义掌握/忽略状态文件的存储路径 |
| 导入 | 从 TXT 导入掌握或忽略词表 |
| 导出 | 导出单词本（Markdown/Anki）、导出掌握/忽略词表 |

### 常规

| 配置项 | 说明 |
|---|---|
| 插件语言 | 自动 / 英文 / 简体中文 |
| 高亮与预览 | 高亮颜色、样式、悬停预览、模糊/折叠释义、掌握按钮开关 |
| 高亮样式 | 下划线样式、粗体、下划线颜色 |
| 高亮范围 | 仅包含/排除指定路径的文件 |
| 查词面板 | 回车模式、本地查询模式、最大结果数 |

### 发音

| 配置项 | 说明 |
|---|---|
| 默认发音语言 | 单词未设置 `lang` 字段时使用 |
| 语言管理 | 新增/编辑/删除语言，为每种语言配置预设代码 |
| 网络 TTS | 预设（有道/百度/Google/自定义）、URL 模板、发音偏好、语速 |
| 系统 TTS | 启用开关、语音选择、语速、音高 |
| 发音测试 | 输入单词测试当前网络 TTS 配置 |

### AI

| 配置项          | 说明                                     |
| ------------ | -------------------------------------- |
| 服务提供商        | OpenAI、DeepSeek、智谱 GLM、通义千问、Ollama、自定义 |
| API 地址/密钥/模型 | 根据服务商自动填充，可手动修改                        |
| API 密钥存储模式   | 官方密钥链 / 本地加密（基于 Vault 派生密钥）            |
| 温度           | 0~2，控制回复随机性                            |

## ❓ 常见问题（FAQ）

**Q: 高亮不生效？**  
A: 请检查设置中「启用自动高亮」是否开启；检查词库文件是否启用；检查当前文件是否在「高亮范围」内。

**Q: 侧边栏显示为空？**  
A: 确保当前文档包含词库中的单词，且这些单词未被标记为「忽略」。如果启用了「侧边栏范围过滤」，请确认当前文件在范围内。

**Q: AI 查询失败？**  
A: 请检查 API 地址、密钥、模型名称是否正确，网络是否通畅。您可以在设置中使用「测试连接」验证。

**Q: 如何在 PDF 中高亮？**  
A: 默认支持 PDF 高亮。确保已启用自动高亮，并等待 PDF 渲染完成。

**Q: 掌握状态丢失？**  
A: 请检查「掌握状态文件」路径是否正确，是否可写。若切换了掌握模式（全局/按词源），插件会自动迁移数据。

**Q: 系统 TTS 没有声音？**  
A: 请检查操作系统是否安装了对应语言的语音包。若无匹配语音，插件会自动回退到网络 TTS。

**Q: 悬停预览/单词卡片中的标签页是如何拆分的？**  
A: 
1. 插件使用 `---`（三个连续的短横线）作为分隔符，将释义文本切分成多个部分，每个部分独立成为一个标签页。
2. 插件会扫描上述每个部分 **开头的加粗文本**（`**加粗文字**`），将其提取为标签页显示的名称。

**示例：** 如果你在 **编辑单词/短语** 模态框的释义框里如下写，就会生成 3 个标签页：

```text
**释义**
放弃，遗弃；丢弃

---

**常用例句**
He abandoned his car in the snow.
他在雪地里丢弃了他的车。

---

**相关短语**
abandon hope 放弃希望
```

3. 如果某个部分没有以 `**标题**` 开头，插件会自动分配默认名称：
   - 第一个部分 → 默认名为 `释义`
   - 后续的部分 → 默认名为 `内容 2`、`内容 3` ……

**Q: 如何快速为自定义提示词绑定快捷键？**  
A: 在 `AI 配置 → 自定义提示词` 区域，点击「设置快捷键」按钮，会自动跳转到 Obsidian 快捷键设置页，并自动搜索过滤本插件的所有命令。您可以为每个「查词提示词：xxx」命令绑定独立的热键，实现一键查词。

**Q: 学习中心的复习算法是怎样的？**  
A: 插件使用简化的 SM-2 算法：
- 每个单词有 0~5 共 6 个等级，达到 5 视为掌握。
- 每次复习根据反馈（忘记/困难/良好/简单）调整等级与难易系数。
- 实际复习间隔 = 基础间隔（可按等级自定义）× 难易系数。
- 连续反馈良好/简单可获得额外难易系数奖励；连续反馈忘记/困难会触发搁置。
- 高级参数可在「学习中心 → 设置 → 高级设置」中调整。

**Q: 词库文件可以放在任意位置吗？**  
A: 可以。词库文件可放在 vault 任意位置。若文件被重命名或移动，插件会自动更新路径。

## 🎨 自定义样式（CSS 片段）

您可以通过 CSS 片段覆盖插件默认样式。以下示例让侧边栏卡片内的高亮词背景色跟随卡片颜色，且透明度为 15%（插件已内置，可在 `styles.css` 中查看）：

```css
.word-card .simple-wordbook-highlight,
.word-card-content .simple-wordbook-highlight,
.lookup-result .word-card .simple-wordbook-highlight {
  background-color: color-mix(in srgb, var(--card-color) 15%, transparent);
  text-decoration: none;
  border-radius: 6px;
  padding: 0 2px;
}
```

更多定制可参考插件 `styles.css` 中的命名空间。
